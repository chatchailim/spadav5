## 2. ยังไม่พร้อมเปิดห้องข้อมูลนักลงทุน

ผลตรวจ SPD-INV-001 รอบแรกคือ **NO-GO** สิ่งที่ต้องปิดก่อน:

1. ยืนยันตัวเลขเงินกู้แปลงสภาพ แล้วให้ทนายร่างสัญญาจาก SPD-INV-003
2. ใส่ banner SUPERSEDED/WITHDRAWN ตามทะเบียนการถอน
3. แทนจำนวนหุ้น placeholder ด้วยตัวเลข บอจ.5 จริง และกรอกเงินสดตั้งต้นกับวันออกเอกสารในโมเดล
4. ทำ PDF ฉบับนักลงทุน (ไม่มี speaker notes SPD-INV-005 และไม่มีหมายเหตุเชิงต่อรองในโมเดล)
5. ให้วิศวกรอิสระทำ evidence pack ข้ออ้างเชิงเทคนิค (INV-C17, C23) และให้ที่ปรึกษากฎหมายตรวจ INV-C27..C31
6. สแกนความลับและประวัติ git (INV-C33, C34)
7. Lead ระบุผู้ตรวจเอกสารและวันก่อนเปิดห้องข้อมูล

### 3.1 ผลตรวจ CI จริง (2026-10-08, อ่านจาก workflow และประวัติการรัน 30 รอบล่าสุดของแต่ละ repo)

- `onemanos-setbox` (branch `master`): CI มีชุดทดสอบแบ่ง 2 ส่วนบน Ubuntu และ Windows, ซ้อมติดตั้งเต็ม, สแกนข้อมูลจริงหลุดเข้าโค้ด, ประกอบชุดส่งมอบ และ `docker-smoke` ที่ build อิมเมจแล้วรอให้ container healthy PR ล่าสุดผ่านทั้งหมด
- `spada-monorepo` (branch `main`): มี CI, Quality Gates, Service CI, Node Images (build/สแกน Trivy/push) และ Windows regression PR ล่าสุดผ่านทั้งหมด
- **ช่องว่างที่พบ:** `ci.yml` ของ `onemanos-setbox` ตั้ง `push` ไว้ที่ branch `main` แต่ branch หลักคือ `master` ใน 30 รอบล่าสุดไม่มีรอบที่รันตอน merge เข้า `master` ยังไม่ได้แก้ (ผมไม่มีสิทธิ์เขียน repo นั้น) ต้องให้เจ้าของแก้หรือให้สิทธิ์เขียน
- ยังไม่ยืนยันว่ามี CD (ปล่อยเวอร์ชัน/เผยแพร่ชุดส่งมอบ) ของ setbox หรือไม่ ผมอ่านไม่ครบทุกไฟล์

### 3.3 สถานะ branch

ทั้งสาม branch ของงานโค้ดยังไม่ merge และไม่มี PR ส่วน POO-WO-006 ที่ส่งต่อ Codex เป็นสถานะ "ออกแล้ว" ยังไม่ทราบว่าเริ่มทำหรือยัง

## 4. เรื่องที่ Lead ต้องตัดสินหรือลงมือ (เรียงตามผลต่อการส่งมอบ)

1. ตรวจและ merge สาม branch ของงานโค้ด (แล้วสั่งให้เปิด PR ตามแม่แบบแต่ละ repo)
2. ตัดสิน dTPM/fTPM และชิป KeySign
3. ตัดสิน ADR 0024–0026 และยืนยันย้อนหลัง ADR 0018–0020
4. กำหนด VM ทดสอบแบบใช้แล้วทิ้ง บัญชีทดสอบและวงเงิน (POO-WO-005) และกรอกตารางมอบงาน
5. ส่งต่อบันทึก SPD-EXC-001 ให้ session Cowork บันทึกใน approval log ของ S20-A (เงื่อนไขข้อ 4)
6. ระบุฟังก์ชันของเครื่องมือ C# เดิมที่ต้องสร้างเพิ่ม และจัดทดสอบ `prep` บน Windows สะอาด
