# ผลทดสอบ: Motion graphics + เพลงประกอบที่ซิงก์กับจังหวะ

**รหัสเอกสาร:** SPD-MED-006 · **สถานะ:** ผลทดสอบเบื้องต้น (ยังไม่ผ่านผู้ตรวจ) · **วันที่:** 2026-10-02

## 1. เครื่องมือที่ติดตั้งและทดสอบแล้ว (ในสภาพแวดล้อมคลาวด์ของเซสชัน)
| เครื่องมือ | ใช้ทำอะไร | ผล |
|---|---|---|
| **GSAP 3** (npm, ใบอนุญาตฟรีสำหรับการใช้งานทั่วไป ตรวจเงื่อนไขก่อนใช้เชิงพาณิชย์) | อนิเมชันแบบ timeline: ข้อความเด้งขึ้น, การ์ดสปริง, ลูกศรลากเส้น | ใช้ได้ สั่ง `timeline.time(t)` ต่อเฟรมได้ ผลซ้ำได้ทุกครั้ง |
| **Playwright + Chromium** (มีอยู่แล้ว) | เรนเดอร์เฟรมละ 1 ภาพ (เฟรม = ฟังก์ชันของเวลา) | ~8 เฟรม/วินาที ที่ 1080p → วิดีโอ 7 นาที (12,600 เฟรม) ใช้ ~25 นาที |
| **librosa 0.11 / scipy** (pip) | วิเคราะห์จังหวะและสเปกตรัมของเพลง | ตรวจจับจังหวะเพลงทดสอบได้ 83.4 BPM (จริง 84) ใช้ป้อนเอฟเฟกต์ |
| **ffmpeg sidechaincompress + loudnorm** | ลดเสียงเพลงอัตโนมัติเมื่อมีเสียงบรรยาย, ปรับความดัง −16 LUFS | ใช้ได้ |
| **Lottie (lottie-web)** (npm) | ไอคอน/อนิเมชันสำเร็จรูป (ถ้ามีไฟล์ JSON) | ติดตั้งแล้ว ยังไม่ได้ใช้ ต้องมีไฟล์อนิเมชันที่ถูกลิขสิทธิ์ |
| **Remotion** (npm 4.0.x มีให้ติดตั้ง) | กรอบงาน React สำหรับวิดีโอ | ยังไม่ติดตั้ง/ทดสอบ เป็นทางเลือกถ้าต้องการโครงสร้างโปรเจกต์ที่ใหญ่ขึ้น (ตรวจเงื่อนไขใบอนุญาตก่อนใช้เชิงพาณิชย์) |

## 2. เพลง
- เว็บคลังเพลงฟรี (Pixabay, Free Music Archive) **ถูกบล็อกจากเครือข่ายของเซสชัน** จึงไม่ได้ดาวน์โหลดเพลงสำเร็จรูป
- ทดสอบเพลงต้นฉบับที่สร้างด้วยโค้ด (`music.py`): 84 BPM, คอร์ด C–Am–F–G, แพด, อาร์เปจจิโอ, เบสนุ่ม, ไม่ใช้ตัวอย่างเสียงของผู้อื่น จึงไม่มีปัญหาลิขสิทธิ์ แต่คุณภาพเป็นระดับ "ทดสอบ" ไม่ใช่งานโปรดักชัน
- ทางเลือกคุณภาพสูงกว่า: (ก) ซื้อ/ขอใบอนุญาตเพลงจากคลังเพลงเชิงพาณิชย์ แล้วใช้ระบบเดียวกันซิงก์ (ข) โมเดลสร้างเพลง เช่น Lyria ผ่าน API ของ Google (ต้องตรวจโควต้า ใบอนุญาต และข้อกำหนดการใช้) (ค) ให้นักแต่งเพลงทำเพลงประจำโครงการ

## 3. สิ่งที่ซิงก์กับเพลง/เสียงบรรยาย
- การ์ดและแผงปรากฏตามจังหวะคำพูดของแต่ละฉาก (spring easing)
- เส้นขอบและแสงของการ์ดเต้นตามจังหวะเพลง (beat grid 84 BPM)
- แท่งสเปกตรัมด้านล่างและขนาดอนุภาคพื้นหลังตอบสนองต่อข้อมูลสเปกตรัมจริงของเพลง
- เพลงถูกลดเสียงอัตโนมัติขณะมีเสียงบรรยาย (sidechain) และมีช่วงเพลงนำ 0.8 วินาทีก่อนคำพูดแรก

## 4. ข้อควรระวัง
- เป็นเดโมเฉพาะ 4 ฉากแรกของวิดีโอวิสัยทัศน์ (SPD-MED-005) ยาว 84 วินาที ใช้เสียงบรรยายเดิม ไม่ได้ใช้โควต้า TTS เพิ่ม
- ยังไม่ได้ทดสอบกับผู้ชม และยังไม่ได้ฟังเพลงด้วยหูมนุษย์ (ผู้ผลิตเป็นเอไอ ไม่มีหูฟัง) ต้องให้คนฟังก่อนตัดสิน
- ไฟล์วิดีโอไม่เก็บใน repo สคริปต์ที่ใช้อยู่ใน `motion-pipeline/` (ไม่มีคีย์ API; `build_demo.py` อ้างไฟล์เสียงที่ผลิตไว้ในสภาพแวดล้อมของเซสชัน จึงเป็นตัวอย่างโครงสร้างมากกว่าสคริปต์ที่รันซ้ำได้ทันที)
- ใช้กับสื่อสาธารณะต้องไม่ทำให้อ่านบรรทัดคำบรรยายยากขึ้น ลดการเคลื่อนไหวสำหรับผู้ชมที่ไวต่อภาพเคลื่อนไหว (ควรมีรุ่นเรียบ)

## 5. ข้อเสนอ
1. ให้คุณดูเดโมนี้ และบอกว่าระดับการเคลื่อนไหวพอดีไหม (มากไป/น้อยไป)
2. ตัดสินใจเรื่องแหล่งเพลง (ต้นฉบับโค้ด / เพลงที่ซื้อใบอนุญาต / Lyria)
3. ถ้าผ่าน ใช้ระบบนี้เรนเดอร์วิดีโอวิสัยทัศน์ทั้งเรื่อง (ใช้เวลาประมาณ 25–30 นาที) และกับคลิปอื่นตามต้องการ
