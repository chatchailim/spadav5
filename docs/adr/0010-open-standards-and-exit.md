# ADR-0010: Open standards และ exit ที่ไม่ต้องขออนุญาต

- สถานะ: Proposed
- วันที่: 2026-09-29
- ระยะ: P0–P2
- ผู้ตัดสินใจ: (รอกำหนด)

## บริบท
ระบบที่ล็อกผู้ใช้ไว้ขัดกับหลัก Human sovereignty; การล้มเลิกโครงการต้องไม่ทำให้ผู้ใช้เสียทรัพย์สินหรือข้อมูล

## ทางเลือกที่พิจารณา
1. รูปแบบเฉพาะของระบบ
2. ใช้มาตรฐานเปิด (W3C DID/VC, ISO 20022) + สิทธิ์ export ครบ + แผน sunset

## การตัดสินใจ (ข้อเสนอ)
เลือกข้อ 2: ทุกข้อมูลและตัวตน export ในรูปแบบเปิดได้โดยไม่ต้องขออนุญาต, reproducible build และ open hardware สำหรับ KeySign/SetBox, กำหนด sunset/exit plan ล่วงหน้า

## ผลที่ตามมา
ข้อดี: ลด lock-in สร้างความไว้วางใจ ข้อเสีย: จำกัดความเป็นเอกลักษณ์เชิงธุรกิจ และการเปิดฮาร์ดแวร์ต้องดูแลความปลอดภัย supply chain

## เกณฑ์ตรวจรับ
- export แล้วนำเข้าระบบอื่นที่ใช้มาตรฐานเดียวกันได้จริง
- reproducible build ตรวจซ้ำได้โดยบุคคลที่สาม
- เผยแพร่ sunset plan

## คำถามที่ยังเปิดอยู่
- ใบอนุญาตซอฟต์แวร์/ฮาร์ดแวร์
- ขอบเขตมาตรฐานที่ต้องรองรับใน P0
