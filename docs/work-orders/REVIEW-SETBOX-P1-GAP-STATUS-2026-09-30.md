## 1. P1 สี่ข้อของผลตรวจ 2026-09-06 เทียบกับซอร์ส

ซอร์สอยู่ที่ `tools/pc12-prep-assistant/src/` (ไฟล์ `OneManOS.PcPrep.Core/PreparationService.cs` 388 บรรทัด และ `OneManOS.PcPrep.App/MainForm.cs`) บนสาขา **wip** ที่ snapshot เมื่อ 2026-09-22 ซึ่งใหม่กว่าที่ผลตรวจอ้าง (HEAD `0f9a1b4`, 2026-09-06) **สาขานี้เป็น snapshot ของงานที่ยังไม่ commit ไม่ใช่ `main`** สถานะจริงบนเครื่องพัฒนา (`D:\codexspace\OneManOS\OneManOS`) อาจต่างออกไป

| P1 | ข้อค้นพบเดิม | สิ่งที่พบในซอร์ส (`b436312`) | สถานะ |
|---|---|---|---|
| 1. signature/manifest ไม่ fail-closed | ไม่มี `manifest.sig` ก็ผ่านเป็น PILOT LIMIT · `files=[]` ก็ผ่าน | ไม่มี `manifest.sig` ยังเพิ่มข้อความ "PILOT LIMIT" และสรุปผลด้วย `messages.All(PASS หรือ PILOT LIMIT)` จึงยังนับเป็นผ่าน · manifest ว่างยังผ่าน (ไม่มีข้อความ BLOCK) | **ยังเปิด** |
| 2. export ไม่บังคับ preflight | `Export()` ไม่ผูกกับสถานะ P0–P4 | `Export()` เรียก `BuildEnvelope()` จากช่อง control ที่ผู้ใช้กรอก แล้ว `ExportEvidence` ไม่พบการอ้างสถานะ preflight ในบรรทัดที่อ่าน | **ยังเปิด (ตามที่อ่าน)** |
| 3. encryption/release PASS เกินหลักฐาน | ใช้ exit code ของ `manage-bde -status` · Node เพียง `--version` | บรรทัด 348 ถือ `ExitCode == 0` เป็น PASS · Node และ npm/Git ตรวจแค่ `--version` ไม่เทียบขั้นต่ำ | **ยังเปิด** |
| 4. network policy ปฏิเสธแล้วยังเชื่อมต่อ | เพิ่ม BLOCK แล้วเรียก `CheckCentralTcp` ต่อ | บรรทัด 125 บันทึก BLOCK แล้วบรรทัด 127 ยังเรียก `CheckCentralTcp(uri)` | **ยังเปิด** |
| P2 path containment | `StartsWith(root)` ไม่ตรวจ separator | บรรทัด ~178 ยังใช้ `candidate.StartsWith(Path.GetFullPath(mediaRoot))` | **ยังเปิด** |

**ข้อสังเกต:** ชุดเทสต์ `tests/OneManOS.PcPrep.Tests/Program.cs` มี negative test ของ audit chain ที่ถูกแก้ และการบล็อกปลายทางสาธารณะ แต่ไม่พบ negative test ของ P1 ข้อ 1–4 ตามเกณฑ์รับงานในผลตรวจ **สรุป: P1 ทั้งสี่ข้อยังไม่ปิดตามซอร์สที่ตรวจ** สถานะ CONDITIONAL ของผลตรวจ 2026-09-06 ยังคงอยู่ ต้องให้ผู้ดูแลยืนยันว่ามีงานแก้ที่ยังไม่อยู่ในสาขานี้หรือไม่
