## 4. A6-lite: ไล่เส้นทางกุญแจด้วย `sim` (เพิ่ม 2026-10-01 ตามที่ Lead เลือกตัวเลือก B)

ทำได้ทันที ไม่ต้องใช้อุปกรณ์ ไม่ต้องมีคนกดปุ่ม ดูข้อกำหนดเต็มใน [SPD-WO-004](SPIKE-TEST-ENVIRONMENT-SPEC-POO-WO-005.md) หัวข้อ A6

1. **แยกทะเบียนก่อนทุกอย่าง** (ค่าเริ่มต้นของ `pktctl` คือทะเบียนจริง):
   ```text
   set SPADA_PKT_REGISTRY=<โฟลเดอร์ทดลองใหม่นอก repo>
   set SPADA_PKT_SIM_STATE=<โฟลเดอร์ทดลองใหม่>\sim-device.json
   ```
   บันทึก SHA-256 ของไฟล์ทะเบียนจริงก่อนและหลัง ต้องเท่ากัน
2. ใช้ `--transport sim` เท่านั้น ถอด REAL-UNIT-1 ออกจากเครื่องที่ทดลอง **ห้ามรัน `enroll`/`sign`/`reset`/`selftest` กับ `pwsh-serial`**
3. ไล่เส้นทาง: UI/CLI → สร้าง assertion → SPADA node ทดสอบตรวจ ตามหัวข้อ A6 ของรายงานเดิม (`A6-signing-path.md`) และทดสอบปฏิเสธ: ใช้ซ้ำ, หมดอายุ, payload เปลี่ยน
4. รายงานแยก ลองแล้ว / อ่านแล้ว / ไม่ทราบ และใส่ป้าย **"SIMULATED: ไม่พิสูจน์ user presence"** ในหัวรายงาน
5. **ห้ามใส่ DID, token ID หรือ uid จริงในรายงานหรือหลักฐาน** ใช้ DID ทดลองเท่านั้น ส่งเฉพาะ `docs/spike/` พร้อม DCO
